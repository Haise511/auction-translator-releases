# Переводчик торгов — обновления

Здесь лежат только установщики переводчика торгов (Kolon, LOTTE, SK, K Car, Glovis) и файл `latest.json`.
Исходного кода здесь нет.

Установленная программа сама проверяет этот адрес при запуске ярлыка «Переводчик …». Если вышла новая версия, она
предлагает её поставить: Enter — сразу, Esc — пропустить. Файл ставится, только если его размер и SHA-256 совпали
с `latest.json`. Логины, курс и разметка окна при обновлении сохраняются.
